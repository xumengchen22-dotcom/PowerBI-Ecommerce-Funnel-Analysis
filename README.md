# 🛒 基于 Power BI 的电商用户行为漏斗与区域异动分析

## 📌 项目背景
在电商平台整体转化率平稳的表象下，往往隐藏着特定区域的业务瓶颈。本项目基于真实的电商行为日志与用户画像数据，使用 Power BI 搭建多维分析看板，通过漏斗模型与切片器下钻，精准定位异常业务区域，为运营决策提供数据支撑。

## 🛠️ 技术栈与核心工具
*   **数据清洗与建模**：Power Query (多表 Join 整合行为与画像表、对 `user_id` 进行去重计数 `Distinct Count` 计算真实 UV)。
*   **数据可视化**：Power BI (漏斗图、切片器 Slicer 多维下钻)。
*   **分析方法**：用户行为漏斗模型、异动归因分析。

## 📊 核心数据洞察

### 1. 大盘整体漏斗（表现平稳）
*   **数据表现**：大盘“浏览-点击”流失率约 50%（处于电商行业正常区间），整体最终加购转化率为 **19.8%**。
*   **结论**：大盘整体行为路径未出现系统性崩塌，需进一步寻找局部异常。


### 2. 区域异常定位（福建省异动）
*   **数据表现**：通过省份切片器（Slicer）下钻发现，**福建省**的最终加购转化率仅为 **16.4%**，显著低于大盘均值（19.8%）。
*   **结论**：福建省存在明显的区域异动，是拉低整体转化率的核心痛点。


## 💡 业务建议与优化策略
1. **物流体验排查**：建议运营排查近期福建省的物流时效与仓储状态，是否因配送延迟导致用户加购意愿降低。
2. **区域定向营销**：针对福建用户定向发放“满减/包邮”专属优惠券，以经济手段刺激加购决策。
3. **竞品动向监测**：排查福建省内是否有强势竞品开展了区域性的价格战或促销活动。
